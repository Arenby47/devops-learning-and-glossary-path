# 🚀 DevOps Learning Path & Glossary

An **interactive DevOps learning platform** that helps beginners understand DevOps concepts through a **terminology glossary, structured learning roadmap, AI assistant, and quiz system**.

This project provides a beginner-friendly way to explore DevOps tools and concepts with interactive features and learning resources.

---

## 📌 Features

### 📚 DevOps Glossary

* Interactive glossary of common DevOps terms
* Clickable cards with explanations
* Direct links to learning resources

### 🔎 Search Functionality

* Quickly search for DevOps terms
* Instantly filter glossary content

### 🛠 DevOps Tool Icons

* Visual icons for tools like Docker, Kubernetes, Jenkins, and Git
* Makes learning more intuitive

### 🧭 DevOps Learning Roadmap

Structured learning stages including:

1. **Fundamentals**

   * Linux Basics
   * Networking
   * Git & GitHub

2. **Containers**

   * Docker
   * Containerization

3. **CI/CD**

   * Jenkins
   * GitHub Actions
   * Pipelines

4. **Infrastructure as Code**

   * Terraform
   * Configuration Management

5. **Orchestration**

   * Kubernetes

6. **Monitoring**

   * Prometheus
   * Grafana

---

### 🤖 DevOps AI Assistant

A built-in chatbot that helps users quickly understand DevOps concepts.

Users can ask questions like:

* What is Docker?
* Explain Kubernetes
* What is CI/CD?

---

### 🧠 DevOps Quiz System

* Multiple choice DevOps questions
* Instant score calculation
* Helps reinforce learning

---

### ⚡ DevOps Pipeline Visualization

A visual representation of the DevOps workflow:

Code → Build → Test → Deploy
